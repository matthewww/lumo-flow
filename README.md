# Lumo Flow

A high-fidelity, self-playing digital signage application designed for public screens. Uses generative WebGL backgrounds, high-end animations, and bold typography to turn informational screens into captivating digital art.

## Tech Stack
- React 18 + Vite + TypeScript
- Framer Motion (Animations & Transitions)
- React Three Fiber / Three.js (Generative Backgrounds)
- Tailwind CSS (Styling)
- Zustand (State Management)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Structure
- `src/components/canvas/` - Three.js WebGL backgrounds
- `src/components/deck/` - Slide display engine and progress systems
- `src/components/slides/` - Individual slide designs
